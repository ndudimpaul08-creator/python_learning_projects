# E-Commerce Sales Analysis

## Overview

This project is an Exploratory Data Analysis (EDA) of an e-commerce dataset. The goal is to analyze sales performance and identify useful patterns using Python.

## Business Questions

- Which products generated the most revenue?
- Which categories generated the most revenue?
- Which region had the most orders?
- Are there any outliers in order values?

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
