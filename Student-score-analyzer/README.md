# Student Score Analyzer

A beginner-friendly Python project for managing student scores and analyzing their academic performance.

## About the Project

The Student Score Analyzer allows users to add students, record their scores, view student information, calculate averages, determine grades, find the student with the highest average, and search for students.

This project was created while learning Python fundamentals and practicing how different Python concepts can work together in one program.

## Features

- Add students and their scores
- View all students
- Calculate total and average scores
- Determine student grades
- Determine pass/fail status
- Find the student with the highest average
- Display available subjects
- Search for a student
- Exit the program through a menu
